Step 1 - Module self-ID (bench, inverter NOT connected)

  1. Module VCC to ESP 3V3, GND to GND, header RXD to GPIO18, header TXD to GPIO16. Never 5 V.
  2. A+ and B- open: run self-ID - expect open-ok (both HIGH).
  3. Jumper A+ to ESP GND and B- to ESP 3V3, run again - the pin that reads LOW is RO. Then remove the jumpers.
Optional bench UART loopback
Only BEFORE the module is wired (do it first): GPIO17 jumpered to GPIO18, module AND inverter disconnected. This transmits the read-only QPI frame on GPIO17 for under a second. Refused once a self-ID or idle test has run.

Step 2 - Idle-level test (receive only)

Wire ONLY: module B- to COM pin 8 (GND) and module A+ to the candidate pin. GPIO17 stays disconnected. Never pin 4. Never touch the BMS jack.

Put A+ on pin 1 and test, then move A+ to pin 2 and test. Repeat the TX pin once more. The inverter's TX pin reads steady LOW (it idles negative).

2b - Upper check of the RX pin (needed before GPIO17)
Unplug the RJ45 and the USB first. Take the pin-8 wire together with the P5 jumper out of B- (they stay joined and on ESP GND; tape the bare pin). Put a jumper from B- to ESP 3V3. Put the RX candidate on A+. B- must never touch 3V3 and GND at the same time. If the board does not boot, unplug at once.

Run it twice. Expected: below-3V3. ABOVE-3V3 means a positive pin (pin 4?): stop. Afterwards undo the jumper and put pin 8 + P5 back into B-.
